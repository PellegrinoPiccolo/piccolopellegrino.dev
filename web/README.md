# piccolopellegrino.dev — web

Next.js frontend for the portfolio. Content comes from Sanity (see `../studio`).

```bash
npm run dev
```

Design tokens (colors, type scale, radii) live in `app/globals.css` as a Tailwind `@theme`; the default Tailwind palette is disabled, so use the token classes (`bg-card`, `text-muted`, `border-line-card`, `text-h2`, `rounded-card`, …).
